Figure 2 - Task decomposition

The big task is split into four sub-tasks, each handled by one prompt, so each prompt has one clear job and its own test.
Run a realistic mock interview and give feedback the student can act on
1. Plan the interview (P1)
Pick topics that fit the role and round
Order questions easy → hard
Write key points of a strong answer (reference for P2)
Refuse fake / unsafe roles
2. Judge each answer (P2)
Score correctness, depth, structure, clarity (1-5)
Quote the student's exact words as evidence
Flag invalid answers and injection attempts
Ignore style: same content = same score
3. Probe the weak spot (P3)
Find the weakest criterion (code)
Ask one follow-up that targets it
Easier re-ask if the answer was invalid
Score the follow-up answer with P2
4. Summarise and coach (P4)
Overall level + the #1 thing to fix
Score table per question
Strengths and gaps backed by quotes
7-day practice plan + next questions
